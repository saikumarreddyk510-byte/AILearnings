A field guide for ML & DS

Linear Algebra, one dimension at a time.

Numbers alone → single scalars. Numbers in order → vectors with direction. Numbers in a grid → matrices that transform data. Everything from a house-price model to a neural network is built out of these three ideas.

X · 1D · Beginner Y · 2D · Intermediate Z · 3D · Advanced

Enduku Linear Algebra Important?

Linear Algebra ante numbers ni single ga kakunda group ga chusi, vatini rules tho operate cheyyadam. Idi ML, DL, NLP, Computer Vision lo chala important — because every one of those fields spends most of its time moving groups of numbers around.

  1. Data ni represent cheyyadaniki (tables, vectors, matrices)
  2. Relations ni ardham chesukodaniki (features madhya relation)
  3. Fast ga calculations cheyyadaniki (matrix operations)
  4. Models train cheyyadaniki (weights updates, transformations)
Analogy

Oka toy box undi ani anuko. Single toy = scalar. Toys ni line lo arrange chesthe = vector. Toys ni rows and columns lo shelf lo arrange chesthe = matrix. That's the entire subject, in miniature — everything below is that idea, scaled up.

§1

Scalars, Vectors, Matrices

1D · Beginner

Scalar — oka single value

No direction, magnitude matrame. temperature = 32, house price = 75.

Vector — magnitude + direction

Order lo values list. Example: student marks vector [85, 90, 78], or a 3D point [2, 3, 4].

Vector ante numerical value ki magnitude (length/size) mariyu direction (e side ki point chestundo) rendu untayi.

Clarity

"45 km/hr" only magnitude kabatti idi scalar. "45 km/hr East direction" ante adhi vector concept (velocity type).

Magnitude — 2D vector |v| = √(x² + y²)
Magnitude — n dimensions |v| = √(x₁² + x₂² + … + xₙ²)
Worked example v = [3, 4] ⇒ |v| = √(3² + 4²) = 5

Two vectors on the plane

Consider A = [1, 2] and B = [-3, 2] — same idea, opposite x-direction.

Decomposing a vector into î and ĵ

Standard basis vectors: î = (1,0) points one unit along x, ĵ = (0,1) points one unit along y — both have magnitude 1. Any point is just a weighted sum of the two.

Unit vector formula û = v / |v| · for v=(3,3): |v| = √18 = 3√2, so û = (1/√2, 1/√2)

Why unit vectors matter in ML

  • Direction-only comparison — removes magnitude, keeps pure direction
  • Cosine similarity is built on normalized vectors
  • Normalization stabilizes training when feature scales vary wildly
Two more quick examples v = (4,0) ⇒ |v| = 4, û = (1,0) = î v = (0,5) ⇒ |v| = 5, û = (0,1) = ĵ

A vector is a displacement, not a position

Same arrow ni slide chesina — starting point marina, ending point marina — direction and length same unte, adi same vector. Vector position kaadu, change ni represent chestundi.

Same direction, different lines

Parallel lines meaning — same slope/direction unna lines family. Center lo origin nundi velle line direction ni represent chestundi; vere parallel lines ante same direction but shifted positions.

Why this matters in ML

  • Feature shift & invariance — absolute location kanna relative differences important ani idea build avtundi
  • Decision boundary intuition — classifier lo boundary line shift ayina slope same unte orientation same untundi
  • Vector operations — add/subtract lo displacement concept direct ga use avtundi
Analogy

Floor meeda oka arrow sticker undi ani anuko. Sticker ni side ki move chesina, arrow direction and length marakapothe, meaning same.

Analogy

Dot Product

[1,2,3] · [4,5,6] = (1×4) + (2×5) + (3×6) = 32

  • Prediction score calculation — this is how a model turns features into a number (see §8)

Vectors in Data Science

1D · Beginner

A student's features, as a vector

IQ = 90, StudyHours = 3 → feature vector [90, 3]. Inko student: [100, 3]. Input features vector form lo model ki velthai; model output scalar/class label istundi.

Vectors can hold anything in order

Person weight, 4 days: [70, 72, 75, 73] — a 4-dimension vector. Real datasets go far beyond 2 or 3 numbers per row; the math doesn't care how many.

Where scalars / vectors / matrices show up in DS

  • Feature representation — one row of values (Area, Rooms, LocationScore) → vector; the full dataset → matrix
  • Target prediction — Price, Sales, Rating are usually a scalar output
  • Similarity — compare two users' interest vectors via dot product / cosine similarity
  • Recommendation systems — user-feature matrix × item-feature matrix
  • Images & text — pixel grids are matrices, embeddings are high-dimension vectors
  • Scaling / normalization — puts mismatched scales (temperature, salary, age) on equal footing
Mini example x = [Area, Rooms, LocationScore] = [1200, 2, 7] w = [0.03, 5, 2] prediction score = w · x + b

From 2D to 3D

2D · Intermediate

A single house, as a point

One house, two features (Area, Price) → a 2D point: (1200, 45).

Add a third feature, NoOfRooms, and the same house becomes a 3D point: (1200, 2, 45) — exactly the vector the widget below plots.

Analogy

2D ante map lo street matrame choosinatlu. 3D ante same street + building floors info kuda add ayinatlu.

One more feature, one more axis

A 2D vector is [x, y]. Add a third number and the point lifts off the page into space: C = [x, y, z], e.g. C = (2, 4, 2). Drag the panel below to rotate it — this is the same î/ĵ decomposition from §1, just with a third basis vector k̂ joining in.

Interactive · vector OC in 3-space drag to rotate · scroll to zoom
C = (2, 4, 2) · |OC| = √(2²+4²+2²) = 4.90

Same idea keeps stacking: 2D → (x1,x2), 3D → (x1,x2,x3), nD → (x1,…,xn). Human eye 3D varaku matrame draw cheyagalam, kani the math doesn't care — a 50-feature row is just a point in 50-dimension space.

Analogy

2 features ante 2 color pencils tho drawing. 10 features ante 10 color pencils tho detail drawing. Colors ekkuva aina, drawing rules maravu — ade linear algebra idea.

§5

Linear Transformations

2D · Intermediate

Shape ni move/rotate/scale — but lines stay straight

A transformation ante shape ni move/rotate/scale cheyyadam, kani straight lines ni straight lines gane unchadam. Every transformation here is just a matrix — î and ĵ get sent somewhere new, and every other point follows along as a weighted mix of the two.

Interactive · a 2×2 matrix bending the unit square pick a preset
M = [ 1.00 0.00 ; 0.00 1.00 ] î → (1.00, 0.00) ĵ → (0.00, 1.00)

Try it

  • Scale stretches along the axes — î and ĵ keep pointing the same way, just longer/shorter
  • Rotate 40° spins everything — no direction survives unchanged
  • Shear slides one axis sideways — the x-axis itself doesn't move
  • Reflect flips the y-axis — a mirror
Analogy

Paper meeda square draw chesi stretch chesthe rectangle avtundi. Adi transformation.

§8

Dot Product → Predictions

2D · Intermediate

House price, as a dot product

Input features: Area, Number of rooms, Location score. Model output: predicted price.

Price = w₁·Area + w₂·Rooms + w₃·LocationScore + b

[Area, Rooms, LocationScore] = vector x  ·  [w₁, w₂, w₃] = weight vector w  ·  prediction = w · x + b

Ante model mostly dot product meeda run avutundi — every linear model in this document is the same three moves: gather features into a vector, weight them, sum.

Categorical features need encoding first

Location text value kabatti model direct ga teesukodu — numeric ga convert cheyyali (encoding) before it can join the feature vector.

§10

Neural Networks: Matrix Multiplication, Twice

3D · Advanced

Same example as §8 — Input features f1 = Area, f2 = NoOfRooms — but now routed through 3 hidden neurons before reaching Price. Two inputs fully connected to three neurons means the input-to-hidden weights form a 2×3 matrix.

Input-to-hidden weight matrix (2 rows for f1,f2 · 3 columns for h1,h2,h3) W₍ih₎ = [ w₁ w₂ w₃ ; w₄ w₅ w₆ ]
Forward step X = [f1 f2] (1×2)   Z₍hidden₎ = X · W₍ih₎   →   shape 1×3

Result shape 1×3 — hidden layer lo 3 neurons ki 3 values vastayi.

Forward vs Backward

Forward propagation: inputs and weights use chesi output predict chestham. Backward propagation: prediction error batti weights (w₁…w₆) update chestham.

Analogy

Forward ante exam attempt chesi marks techukovadam. Backward ante mistakes chusi next attempt lo improve avvadam.

§11

Optimization & Gradient Descent

3D · Advanced

Fitting a line, step by step

Simple linear model: y = mx + c (general line form: ax + by + c = 0 — same idea, just rearranged). Simple regression lo, m (slope) and c (intercept) rendu scalar values — main goal: correct m, c find cheyyali, so predictions points ki close ga ravali.

SizePrice
100045
150065
200085
Step 1 — slope from the endpoints m = (y₂−y₁)/(x₂−x₁) = (85−45)/(2000−1000) = 40/1000 = 0.04
Step 2 — intercept (substitute point 1) 45 = 0.04(1000) + c  ⇒  c = 5
Final modelŷ = 0.04x + 5
Step 3 — predict at x = 1800ŷ = 0.04(1800) + 5 = 77
Step 4 — error, if actual price is 80 error = 80 − 77 = 3   →   squared error = 3² = 9

Every point ki squared error calculate chesi average tiskunte MSE vastundi. m ekkuva unte line steep ga untundi; c marite line up/down shift avutundi.

Many possible lines — which is best?

Objective — mean squared error Loss = (1/n) Σ (yᵢ − ŷᵢ)²     target: min Loss

Gradient Descent — the optimizer

Gradient descent ane optimizer slope/intercept (or weights) ni step-by-step update chestundi, loss tagge direction lo move avutundi.

Update ruleθ₍new₎ = θ₍old₎ − η · ∇Loss

θ = parameters (m, c)  ·  η = learning rate  ·  ∇Loss = gradient direction

Analogy

Hill paina nunchi kindaki digetappudu, every step lo ekkada slope kindaki untundo akkadike move avvadam. Alane gradient descent error-hill lo minimum point ki velthundi.

§12

Quick Revision

Scalar

A single number — magnitude, no direction.

Vector

An ordered list of numbers — magnitude + direction.

Matrix

A table of numbers — rows × columns.

Dot product

A weighted sum — the engine behind every prediction score.

Matrix multiplication

The transformation engine — bends, scales, and rotates space.

Eigen concepts

Directions a transformation leaves alone, plus how much they stretch.

Gradient descent

Nudge parameters downhill on the error surface, one step at a time.

ML core math

Almost every prediction reduces to w · x + b.

Imagine a crayons box: red, blue, green crayon counts = vector. Class lo andari crayons counts table = matrix. Teacher total colors power calculate chesthe = dot product laga. Crayons ni rotate chesi new pattern create chesthe = transformation. Ila chusthe Linear Algebra scary kadu — pattern game la untundi.
